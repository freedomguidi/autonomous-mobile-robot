# Autonomous Mobile Robot  🤖

**An Autonomous Mobile Robot Simulation Project**

## 📌 Overview

This is a personal robotics project focused on the design, development, and simulation of an autonomous mobile robot using ROS 2 and Gazebo.

The main goal is to progressively develop a robot capable of navigating autonomously, avoiding obstacles, and reaching predefined target positions in a simulated environment.

## 🎯 Project Objectives

- Understand and master ROS 2 fundamentals.
- Design and simulate a mobile robot.
- Implement autonomous navigation algorithms.
- Develop obstacle detection and avoidance systems.
- Explore mapping and localization techniques.
- Build a foundation for future real-world robotic applications.

## 🛠️ Technologies & Tools

- **Operating System:** Ubuntu
- **Robotics Middleware:** ROS 2
- **Simulation:** Gazebo
- **Visualization:** RViz
- **Programming Languages:** Python and C++
- **Version Control:** Git and GitHub
